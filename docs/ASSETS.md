Das Bild ist das offizielle WebRadio-Tray-Icon aus dem Upstream-Repository. Es
wurde weder neu gezeichnet noch farblich verändert; die Website skaliert es
lediglich per CSS/`next/image`. Das Logo wird auf einer hellen Fläche
dargestellt, damit der schwarze Schriftzug auch im dunklen Layout lesbar bleibt.

Weitere Grafiken (Screenshots, Theme-Vorschauen, Partnerlogos) werden nicht
verwendet. Für den Website-Katalog werden ausschließlich vom jeweiligen
Entwickler hinterlegte, validierte HTTP(S)-Bild-URLs angezeigt.
